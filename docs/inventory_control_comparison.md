# 容积控制方式对比报告：显式物理储罐 vs 隐式一阶滤波

**日期**: 2026-04-25  
**仿真配置**: `src/configs/inv_implicit.json` vs `src/configs/default.json`  
**对应数据**: `results/inv_implicit_*.npz` vs `results/default_pi_*.npz`

---

## 一、问题背景

在引入显式容积控制储罐（`_storage_tank_control.py`）之前，系统的功率调节通过一个**隐式一阶线性滤波器**实现：

```python
# 隐式模式（原先代码）
alpha_P += (alpha_cmd - alpha_P) * dt / TAU_INV
P_lo = P_lo0 * alpha_P
```

这产生了典型的**双时间尺度弛豫恢复**现象：
- 快速时间尺度（τ_fast ≈ 20s）：轴系惯性响应，转速快速下降
- 慢速时间尺度（τ_slow ≈ 120s）：库存压力恢复，转速缓慢回升

引入显式储罐后，系统调节过程的偏移量显著减少，双时间尺度特征弱化。本报告从原理上分析两者的差别。

---

## 二、两种容积控制方式的本质差别

### 2.1 隐式一阶滤波（`mode: "implicit"`）

**数学模型**：
```
dα_P/dt = (α_cmd - α_P) / τ_inv        [线性一阶ODE]
P_lo(t) = P_lo0 × α_P(t)
ṁ(t)    = ρ(P_lo, T1) × V̇_ref
```

**特征**：
- `α_P` 是一个**抽象状态变量**，没有对应的物理实体
- 响应完全由 `τ_inv = 30s` 决定，是**线性、时不变**的
- `P_lo` 的变化速率 = `(α_cmd - α_P) × P_lo0 / τ_inv`，与当前压力无关
- 没有阀门、没有储罐质量守恒、没有压差驱动
- 等效于假设存在一个"无限大"的理想储罐，可以瞬间提供任意质量流量

**双时间尺度的来源**：
```
τ_fast ≈ J·ω²/P = 62s  （轴系惯性，角动量ODE）
τ_slow ≈ τ_inv + τ_thermal = 30 + 89 = 119s  （库存+热惯性）
```
两个时间尺度相差约 2 倍，产生明显的双指数弛豫：
```
n(t) ≈ n₀ + A·[exp(-Δt/τ_slow) - exp(-Δt/τ_fast)]
```
转速先快速下降（τ_fast 主导），再缓慢恢复（τ_slow 主导），形成明显的"下冲-恢复"双峰结构。

### 2.2 显式物理储罐（`mode: "pi"` / `"pid"` / `"open_loop"`）

**数学模型**：
```
ṁ_valve = u_v × ṁ_max                  [阀门执行器]
dP_lo/dt = -R·T1/V_sys × ṁ_valve       [低压侧压力ODE]
dm_inv/dt = ṁ_valve                     [储罐质量ODE]
dP_inv/dt = R·T_inv/V_inv × ṁ_valve    [储罐压力ODE]
u_v = PI(α_actual - α_cmd)             [PI控制律]
```

**特征**：
- `P_lo` 是**真实物理状态变量**，由质量守恒和理想气体方程决定
- 阀门流量 `ṁ_valve` 受储罐容积 `V_inv` 和最大流量 `ṁ_max` 限制
- PI 控制器使 `α_P → α_cmd` 的响应**更快且更精确**（有积分消除稳态误差）
- 储罐质量有限，大扰动时会出现储罐压力变化（非线性效应）
- 系统有**三个耦合的ODE**（P_lo, m_inv, P_inv），而非一个

**双时间尺度弱化的原因**：
PI 控制器的积分项使 `α_P` 更快地跟踪 `α_cmd`，等效的"库存响应时间常数"从 `τ_inv = 30s` 缩短至 `τ_eff ≈ 1/(Ki × K_v) ≈ 5-10s`。当 `τ_slow ≈ τ_fast` 时，双指数结构退化为单指数，"下冲-恢复"特征消失，转速偏移量减小。

## 三、仿真结果对比

### 3.1 数值结果

| 指标 | 隐式一阶滤波 | 显式 PI 储罐 | 差异倍数 |
|------|------------|------------|---------|
| **5% 阶跃超调量** | 0.227% | **0.014%** | 16× |
| **50% 阶跃超调量** | 2.58% | **0.35%** | 7.4× |
| **5% 阶跃 t_min** | 30 s | 20 s | — |
| **50% 阶跃 t_min** | 30 s | 20 s | — |
| **50% 阶跃调节时间** | 88 s | 20 s | 4.4× |
| **n_final 偏差** | 3.4 rpm | 3.4 rpm | 相同（调速器决定） |

### 3.2 物理解释

**超调量差异（16×）**：

隐式模式下，`α_P` 以 `τ_inv = 30s` 缓慢跟踪 `α_cmd`。在 `t ∈ [t_step, t_step + τ_inv]` 期间，`P_lo` 仍接近设计值，`ṁ` 仍接近设计值，但电机功率已降低 5%。净扭矩缺口 `Δτ = -0.05 × P_cmd0 / ω` 持续 ~30s，积累了较大的转速偏差。

显式 PI 模式下，PI 控制器在 `t_step` 后立即开始抽气，`P_lo` 在 ~5s 内开始下降，`ṁ` 随之减少，`W_comp` 减少，净扭矩缺口迅速缩小。扭矩缺口持续时间从 ~30s 缩短至 ~5s，超调量减少约 6 倍。

**调节时间差异（4.4×）**：

隐式模式的调节时间由 `τ_slow = τ_inv + τ_thermal ≈ 119s` 决定，需要 ~3τ_slow ≈ 360s 才能完全稳定（但调速器在 ~88s 时已将转速拉回 ±0.5% 范围）。

显式 PI 模式的等效时间常数 `τ_eff ≈ 5-10s`，调节时间约 20-30s。

### 3.3 双时间尺度结构分析

**隐式模式**（双时间尺度明显）：
```
τ_fast = 62s  （轴系惯性）
τ_slow = 30 + 89 = 119s  （库存 + 热惯性）
比值 τ_slow/τ_fast ≈ 1.9  → 双指数结构清晰可见
```

**显式 PI 模式**（双时间尺度弱化）：
```
τ_fast = 62s  （轴系惯性，不变）
τ_eff  ≈ 5-10s  （PI 控制器加速了库存响应）
比值 τ_fast/τ_eff ≈ 6-12  → τ_eff << τ_fast
```
当 `τ_eff << τ_fast` 时，库存控制响应远快于轴系惯性，系统退化为**单时间尺度**（由轴系惯性主导），双指数结构消失，转速偏移量减小。

## 四、物理意义总结

| 方面 | 隐式一阶滤波 | 显式物理储罐 |
|------|------------|------------|
| **物理实体** | 无（抽象滤波器） | 有（储罐 + 阀门 + 管道） |
| **状态变量** | α_P（无量纲） | P_lo, m_inv, P_inv（物理量） |
| **响应机制** | 线性指数衰减 | 非线性 PI 控制 + 质量守恒 |
| **等效时间常数** | τ_inv = 30s（固定） | τ_eff ≈ 5-10s（由 PI 增益决定） |
| **双时间尺度** | 明显（τ_slow/τ_fast ≈ 1.9） | 弱化（τ_eff << τ_fast） |
| **大扰动非线性** | 无（线性系统） | 有（储罐容量限制） |
| **稳态精度** | 有稳态偏差（比例调速器） | 有稳态偏差（相同调速器） |
| **物理可解释性** | 低（参数化模型） | 高（对应真实工程部件） |

**结论**：隐式一阶滤波是对容积控制过程的**宏观参数化近似**，适合系统级分析和双时间尺度动力学研究（如 Zhang2020 的解析解推导）。显式物理储罐是对容积控制的**机理建模**，能更准确地反映实际系统的调节性能，但双时间尺度特征因 PI 控制加速而弱化。两者在工程应用中各有价值：前者适合理论分析，后者适合控制器设计和性能评估。
